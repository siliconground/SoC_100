# SoC 100
Digital Semiconductor 개발을 위한 기본적인 도구들을 학습합니다.

## 😃 어서오세요
환영합니다!
SoC 100에서는 반도체 설계에 입문한 여러분들을 위해 반도체 디자인에 필요한 기초적인 도구적 지식에 관한 다양한 세션들을 준비했어요! 
교과서에서 배울 수 없는 다양한 Devlopment Environment, Tool 및 자동화(Automation)을 위한 다양한 지식들을 살펴보아요^^

## 🍕 구성과 세션은 다음과 같아요
  
1. **Socio-economical Background of Semiconductor Design Development**
* 반도체 발전을 지탱해 온 다양한 모멘텀을 살펴보고 우리가 앞으로 가야할 지향점을 살펴 보아요!

2. **Linux**
*  반도체 디자인과 EDA Tool의 발전을 가져온 Unix/Linux 시스템을 살펴보고 기본적인 운영 능력을 키워보아요!

3. **SCM(Source Control Management)**
* Digital IC 프로젝트를 위한 Repository를 구성하고 협업을 위한 환경 설정을 해 보아요! 취업을 위한 포트폴리오 작성을 덤이죠^^

4. **Shell Scripting**
* 리눅스의 기본 커맨드를 바탕으로 복잡한 업무에 대해 자동화를 C-Shell 을 통해 진행해 보아요!

5. **Makefile**
* 기본적인 C 언어 개발을 설정하고 Makefile이 우리의 스트레스를 얼마나 줄여줄 수 있는지 살펴 보아요!

6. **TCL Programming**
* 모든 EDA 솔루션의 자동화와 뗄레야 뗼 수 없는 TCL Scripting의 기본을 살펴보아요!

## 🔐 실무 개발환경을 고려하여 구성했어요
* 핫한 기업의 JD(Job Description)을 고려하여 취업에 꼬옥 필요한 기술들을 반영했어요^^ 여러분은 이 수업을 통해서 남들보다 두어 걸음 이상 앞서갈 수 있어요!

## 🛠️ 도구 모음 및 개발 환경은 다음과 같아요
 - [WSL](https://learn.microsoft.com/ko-kr/windows/wsl/install) : Windows 상에서 Linux 사용을 편리하게 해주는 똑똑한 Hypervisor
 - [Git SCM](https://git-scm.com/) : Code Base의 협업을 위한 놀라운 SCM 솔루션
 - [GitHub](https://github.com/) : Git Repository를 Cloud 상에서 운영하게 도와주는 오픈소스 개발자들의 성지
 - [GNU Make](https://ftp.gnu.org/old-gnu/Manuals/make-3.80/html_node/make.html) : 리눅스에 내장되어 복잡하고 반복적인 작업을 편리하게 해주는 핵 인싸템
 - [TCL/TK](https://www.tcl-lang.org/) : 반도체 설계 소프트웨어의 자동화를 위한 1황 Script Language
